## 2. Bonus: Export Any Website as design.md

Available via Claude Code slash command:
`/design-md <PASTE_URL>` (defined in `.claude/commands/design-md.md`)

Or using the standard prompt:
```text
Act as a senior UX/UI designer. Analyze the website below and generate a detailed design documentation in clean Markdown format.
URL: [PASTE_URL]
Include:
- Overview (purpose, audience, value)
- Information architecture
- Page layout breakdown
- UI components
- Design system (colors, typography, spacing, tokens)
- Responsive behavior
- Interaction patterns
- Strengths & improvements
Structure it professionally using proper Markdown headings so it can be saved directly as design.md. If something is unclear, make reasonable design assumptions.
```
