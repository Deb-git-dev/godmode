# Linear Dark — DESIGN.md Reference Spec

> Source: `MarcBender-git/awesome-design` & `voltagent/awesome-design-md`

## 1. Color Palette
- Canvas: `#0B0F19` (Obsidian Deep)
- Surface 1: `#111827` (Void Surface)
- Surface 2: `#1E293B` (Elevated Panel)
- Primary Accent: `#6366F1` (Indigo Glow)
- Secondary Accent: `#06B6D4` (Cyan Pulse)

## 2. Typography
- Headings: Space Grotesk (`tracking-tight`, `text-balance`)
- Body: Inter (`leading-relaxed`, `text-pretty`)
- Code: JetBrains Mono

## 3. Surface & Geometry
- Double-bezel outline: 1px outer `#334155` + 1px inner `rgba(255, 255, 255, 0.04)`.
- Radius: `16px` cards, `8px` buttons.
