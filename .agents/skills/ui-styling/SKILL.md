# UI Styling Skill

## Responsive Breakpoints
- Mobile: `< 640px` (single-column fluid stacking)
- Tablet: `640px - 1024px` (two-column balance)
- Desktop: `> 1024px` (three-column high-density bento grid)

## Interaction States
- Hover: Subtle luminance increase (`brightness-110`) and gentle scale (`scale-[1.01]`).
- Focus-Visible: 2px offset outline with high contrast accent (`ring-2 ring-accent-primary ring-offset-2 ring-offset-canvas`).
- Active: Tactile depression (`scale-[0.98]`).
