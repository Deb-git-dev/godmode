# High-End Visual Design Skill

## Agency-Grade Polish
1. **Mathematical Spacing**: Standardize vertical rhythm on 8px multiples (`py-2`, `py-4`, `py-8`, `py-12`, `py-16`).
2. **Glassmorphic Subtlety**: Low opacity fills (`bg-slate-900/60`), heavy backdrop blur (`backdrop-blur-xl`), and crisp border stroke (`border-slate-800/80`).
3. **Motion Harmony**: Spring dynamics (`type: 'spring', stiffness: 300, damping: 25`) with deterministic fallback to instant CSS transitions when reduced motion is detected.
4. **Color Saturation**: Keep base surfaces completely neutral (`#0B0F19`, `#111827`); concentrate vibrant accents exclusively on interactive focal points.
