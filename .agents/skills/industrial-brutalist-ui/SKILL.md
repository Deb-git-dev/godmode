# Industrial Brutalist UI Skill

## Aesthetic Architecture
- **Utilitarian Headers**: Exposed grid lines (`border-slate-800`), technical numbering (`[01]`, `[02]`), and status flags.
- **Monospace Priority**: All system metrics, IDs, timestamps, and hashes formatted in `JetBrains Mono`.
- **High-Density Information**: Compact tables with crisp horizontal separator rules, high-contrast badges (`bg-slate-900 border border-slate-700`).
- **Tactile Inputs**: Chunky buttons, high-visibility keyboard focus rings (`focus:ring-2 focus:ring-accent-primary focus:ring-offset-2 focus:ring-offset-slate-950`).
