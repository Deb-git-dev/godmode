# Image to Code Skill

## Reconstruction Protocol
1. **Deconstruct Layout**: Identify flex/grid structures, padding hierarchies, and nested cards.
2. **Extract Tokens**: Match colors to declared tokens in `DESIGN.md`.
3. **Map Primitives**: Wrap dynamic cards with `ParallaxTotem` or `MotionFocus`.
4. **Enforce Types**: Produce fully typed TypeScript props with zero placeholder logic.
