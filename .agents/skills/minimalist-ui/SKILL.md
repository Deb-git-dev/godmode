# Minimalist UI Skill

## Principles
1. **Disciplined Bento Grids**: Asymmetrical grid configurations (1:2, 2:1, 3-column splits) that prioritize content hierarchy over uniform card tiling.
2. **Warm Monochrome**: Deep obsidian darks with warm gray secondary typography (`#94A3B8`, `#64748B`).
3. **Editorial Typography**: Large high-contrast headlines (`text-4xl`, `text-5xl`) with generous negative space and tight letter tracking (`-0.02em`).
4. **Zero Fluff**: Omit unnecessary decorative badges, generic illustrations, or decorative dividers.
