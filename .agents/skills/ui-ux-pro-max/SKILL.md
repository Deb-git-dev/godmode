# UI/UX Pro Max Skill

## Core Purpose
Enforces professional UI/UX design discipline across frontend code generation, preventing generic AI aesthetic slop and enforcing mathematically harmonious spacing, typography, and contrast.

## Token Engine
- Primary Color Harmony: Calculate 60-30-10 distribution (60% background/canvas, 30% surface/structure, 10% high-energy accent).
- Contrast Compliance: Strictly satisfy WCAG AA ratio (minimum 4.5:1 for normal text, 3:1 for large text and UI components).
- Typography Pairings: Display/Heading font paired with high-legibility body font and monospace metrics font.
- Spatial Grid: 4px / 8px hard grid system for padding, margins, and gaps.

## Execution Checklist
1. Analyze user prompt requirements and brand identity.
2. Formulate explicit design system declaration before generating components.
3. Validate interactive states: hover, focus-visible, active, disabled, loading, empty, and error.
4. Verify responsive reflow across Mobile (360px), Tablet (768px), Desktop (1280px), and Ultra-wide (1920px).
